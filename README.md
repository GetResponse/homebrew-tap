# GetResponse/homebrew-tap

```sh
brew install getresponse/tap/skillcask                            # CLI
brew install getresponse/tap/skillcask getresponse/tap/skillcask-app   # CLI and macOS app
```

Formulae and casks are published automatically by the
[skillcask](https://github.com/GetResponse/skillcask) release workflow.

This tap was `puniserv/homebrew-tap`. A tap added under that name keeps working, since GitHub
redirects the old URL; `brew upgrade skillcask` updates it.
